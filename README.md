Arrays and Array Lists are similar but have two distinct difference that I think matter functionally. The first is that while an Array is of a fixed size (you cannot ever chance the size of an Array), you can modify the size of an Array List after it's creation. The second difference is that they are interacted with differently meaning different code is used to call to and or manipulate them. One way this manifests was important in my code which is that you us length when finding the number of elements in an Array but you use size when finding the number of elements in an Array List. There are other things different here like using 'int' for Arrays but 'Integer' for Array Lists.


I've made a VERY simple example of an Array and Array List and added it to my GitHub. All my array example does count up. I didn't OVERLY simplyify it, though, in so far as I did not start counting at 0, even though Array's are indexed starting at 0.
